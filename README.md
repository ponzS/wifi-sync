# WiFi Sync

一个轻量的局域网文件与文本共享工具。只需在一台电脑上启动服务，同一 Wi-Fi 或局域网中的手机、平板和电脑就能通过浏览器交换文件、同步文本，无需安装客户端。

后端使用 Go，前端使用原生 HTML、CSS 和 JavaScript，无需 Node.js、前端构建工具或数据库。文件和协作文本保存在运行服务的机器上。

## 功能

- **文件共享**：拖放或选择文件上传，支持多选后依次上传；在共享列表中下载、删除文件。
- **传输进度**：显示上传、下载的进度、已传输大小和平均速度。
- **文件概览**：查看文件大小、类型、修改时间、下载次数，以及共享文件总数和总大小。
- **扫码访问**：自动识别本机局域网 IPv4 地址并生成访问二维码，方便其他设备加入。
- **协作文本**：多设备共同编辑文本，通过 SSE 实时同步，支持复制、清空、版本显示和并发编辑操作合并；内容自动保存，重启后恢复。
- **在线状态**：通过心跳统计活跃浏览器会话，每 15 秒更新，超过 45 秒未收到心跳的会话不再计入。
- **适配不同设备**：响应式布局、深色与浅色主题，以及上传、下载、删除等操作的活动日志。

## 快速开始

安装 Go 1.25.4 或更高版本，然后执行：

```bash
git clone https://github.com/ponzS/wifi-sync.git
cd wifi-sync
go run .
```

首次运行会下载 Go 模块依赖，服务默认监听 `:8766`。在本机打开：

```text
http://localhost:8766
```

终端会输出局域网访问地址，例如 `http://192.168.1.100:8766`。其他设备连接到同一局域网后，打开该地址或扫描页面中的二维码即可使用。按 `Ctrl+C` 停止服务。

### 自定义监听地址

通过环境变量 `ADDR` 设置监听地址和端口。

macOS / Linux：

```bash
ADDR=:8080 go run .
```

Windows PowerShell：

```powershell
$env:ADDR = ":8080"
go run .
```

如果只供本机使用，可以设置为 `127.0.0.1:8766`。

### 编译运行

macOS / Linux：

```bash
go build -o wifi-sync .
./wifi-sync
```

Windows PowerShell：

```powershell
go build -o wifi-sync.exe .
.\wifi-sync.exe
```

运行时必须从包含 `public/` 的目录启动。前端资源没有嵌入可执行文件；将程序复制到其他机器时，需要一起复制 `public/` 目录，目标机器无需安装 Go。

## 使用方法

1. **上传文件**：将文件拖入上传区域，或点击“选择文件”。多选文件会依次上传，完成后显示在共享列表中。
2. **接收文件**：在另一台设备打开共享页面，点击“刷新列表”，再点击对应文件的“下载”。
3. **管理文件**：点击“删除”并确认，会直接删除服务端的共享文件。
4. **共享文本**：在“协作文本”中输入或粘贴文字，其他已连接页面会同步更新。点击“复制”复制当前文本；“清空”会同步清空所有设备看到的内容。
5. **切换外观**：使用“外观”区域的深色、浅色按钮切换主题。

## 数据保存与限制

所有数据路径均相对于程序的当前工作目录：

| 路径 | 用途 |
| --- | --- |
| `public/index.html` | 网页界面及前端逻辑，运行时需要保留 |
| `uploads/` | 上传文件，启动时自动创建 |
| `.download-counts.json` | 下载次数，重启后恢复 |
| `.board-state.json` | 协作文本、版本与更新时间，重启后恢复 |

运行数据已通过 `.gitignore` 排除，不会随代码提交。备份时请保存 `uploads/` 和两个状态文件。

- 单次上传请求的上限为 **8 GiB**，包含 multipart 表单开销，因此实际文件大小需要略小于此值。
- 上传同名文件会**覆盖原文件**，并重置该文件的下载次数。
- 网页下载会先将完整文件接收为 Blob，再触发保存；大文件下载能力受浏览器和设备资源限制。
- 文件列表支持手动刷新；协作文本通过实时连接自动同步。
- 在线人数按浏览器会话统计，不代表独立设备或真实用户人数。
- 当前没有登录、访问权限控制或内置 HTTPS。任何能访问服务的设备都可以上传、下载、删除文件及修改协作文本，适合在可信局域网中使用。

## 常见问题

**其他设备无法访问？**

确认设备处于同一局域网，使用服务端的局域网 IP 而非 `localhost`，并允许系统防火墙放行监听端口。访客 Wi-Fi 或路由器的客户端隔离可能阻止设备互相访问。

**二维码里的地址无法连接？**

多网卡、VPN 或虚拟网卡可能影响自动选择的地址。请使用终端输出中属于当前局域网的地址手动访问。

**编译后的程序能启动，但网页打不开？**

检查启动时的工作目录是否包含 `public/index.html`。仅复制可执行文件不会包含网页资源。

**上传失败？**

检查文件是否超过请求大小上限、磁盘空间是否充足，以及当前目录是否可写。如果使用反向代理，还需检查代理的请求大小和超时配置。
